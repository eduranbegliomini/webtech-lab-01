## Interactive Features (Lab 02)

1. **Dark Mode Toggle:** Located in the header; click the "Toggle Dark Mode" button to switch the visual theme between light and dark mode.
2. **Interactive Course Collection:** Located in the "My University Courses" section; use the controls to filter by track or minimum grade, complete the form to add a new course, or click "Remove" on any item to delete it.
3. **Form Validation:** Located in the "Contact Me" section; click "Send Message" with empty or invalid fields to display inline error messages, or fill out all fields correctly to see the confirmation message.
